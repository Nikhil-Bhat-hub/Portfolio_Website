## Featured Work

### 1. Pneumonia Detection & Risk Stratification
A deep-learning research project that analyzes chest X-ray images for pneumonia classification. The pipeline combines image preprocessing, data augmentation, attention mechanisms, and Grad-CAM explainability.

**Technology:** Python, TensorFlow, DenseNet121, Grad-CAM  
**Reported evaluation:** PR-AUC 0.9683 · MCC 0.81 · approximately 0.03 false-negative rate  
The research was accepted for presentation at MIKE 2025.

### 2. Routewise Bengaluru — Route Planning
A route-planning project using OpenStreetMap road data, graph-search comparisons, multi-stop ordering, and traffic-aware estimated arrival times with an OSRM fallback.

**Technology:** FastAPI, Leaflet, OSRM, graph algorithms  
**Source code:** [Optimised Route Finder](https://github.com/Nikhil-Bhat-hub/Optimised-Route-Finder)

### 3. SchemeReady — Explainable Scheme Matching
A team project focused on helping users identify relevant public-benefit schemes. Its matching module analyzes a beneficiary profile and explains recommendations against scheme guidelines.

**Technology:** .NET 8, React, MS SQL Server, DigiLocker

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Nikhil-Bhat-hub/Portfolio_Website.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio_Website
   ```

3. Open `index.html` in your browser.

   For a local development server, you can use the VS Code **Live Server** extension.

## Deployment

The website can be hosted using **GitHub Pages**:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Save and wait for GitHub Pages to publish the site.

If you use a different hosting provider, deploy the repository as a static site with `index.html` as the entry point.
